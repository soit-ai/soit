# Getting Help

## Documentation

Start with the documentation:

- Product and operations docs: <https://docs.soit.ai>
- Quickstart: [docs/quickstart.md](docs/quickstart.md)
- Local development: [docs/development.md](docs/development.md)

## Questions and Discussions

Use [GitHub Discussions](https://github.com/soit-ai/soit/discussions) for
usage questions, ideas, and show-and-tell. Issues are reserved for confirmed
bugs and scoped feature requests; questions filed as issues will be converted
to discussions.

## Bug Reports

Open a [bug report](https://github.com/soit-ai/soit/issues/new/choose) with
the version, deployment method, reproduction steps, and sanitized logs.

## Security Issues

Never report vulnerabilities in a public issue or discussion. Follow the
private process in [SECURITY.md](SECURITY.md).

## Commercial Support

SOIT Enterprise and SOIT Cloud include commercial support. See
<https://soit.ai> for details.
