# SOIT v1.5.1 Release Notes

Status: released on 2026-10-01 as tag `v1.5.1` (commit `8221f57`); `soit-cli` 1.5.1 is on PyPI.

## Highlights

- The `soit` command line is published to PyPI as
  [`soit-cli`](https://pypi.org/project/soit-cli/): install it with
  `uv tool install soit-cli` or `pipx install soit-cli`. The command and the
  `soit_cli` import package are unchanged. v1.5.0 announced `soit-ai-cli`,
  but its upload did not run, so nothing was published under that name.

The server, the knowledge worker and the web console are the same as in
v1.5.0 apart from their version.

## Database Compatibility

- Fresh installations migrate from `base` to `20261001110000`.
- This release adds no migrations: a v1.5.0 database needs none.
- The supported N-1 upgrade range stays `20260927160000..20261001110000`.

## Upgrading

1. Nothing to migrate. Restart the API and workers on the new images, or
   stay on v1.5.0: only the command line's distribution changed.
2. A command line installed from the repository can be replaced with
   `uv tool install soit-cli`.

## Known Limitations

- The known limitations of v1.5.0 still apply.
